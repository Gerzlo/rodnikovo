# Родниково — заметки для работы над кодом

- Веб-игра (площадка для выпуска пока не выбрана): HTML + CSS + JS-модули, без сборки и без библиотек. Отвечать Адаму по-русски, коротко и простыми словами.
- Перед каждым push: `npm test` (генератор + браузерный тест Playwright). Найденную ошибку сначала воспроизвести тестом, потом исправить. Тестовый доступ — `window.__rodnikovo` (только чтение).
- Известные проблемы — в `KNOWN` в `tests/playtest.js`: такие проверки не валят прогон. Когда проблему исправили — убрать её из `KNOWN`.
- GitHub Actions (`.github/workflows/deploy.yml`) прогоняет тесты и публикует на GitHub Pages только при зелёных тестах.
- Объекты в клетках ставятся по центру своих габаритов: реестр `OBJECTS` в `js/art.js`, новые постройки добавлять туда.
- На телефоне игра только вертикальная: боком (сенсорный экран, высота ≤ 500 px) показывается заставка `#rotate` «Поверни телефон» (CSS-медиазапрос), цикл отрисовки в это время стоит. Компьютер и планшет не затрагиваются.
- Масштаб страницы заблокирован: meta viewport (`maximum-scale=1, user-scalable=no`), `touch-action:none` на body, отмена `gesturestart` в `main.js`. Без этого на iPhone в режиме «На экран Домой» масштаб залипает (~1,09 после поворота или щипка): шапка уезжает под строку времени, края обрезаются. Не убирать — тест это проверяет.
- `js/core.js` не должен зависеть от браузера: его импортирует тест генератора в Node.
- Улицы задаются зерном в `js/levels.js` — изменение генератора меняет все улицы, после этого перепроверить лимиты ходов и прохождение. Проверка, что старые улицы не изменились: сравнить `generate()` всех улиц до и после.
- Сети: `w` вода → дома, `e` свет → фонари, `g` газ → теплицы (`LEAF` в `core.js`). Источник первой сети — внизу поля, второй — вверху, третьей — в середине. Размер улицы не больше 6×8: иначе на iPhone SE (320×568) клетка меньше 40 px.
- Карта прокручивается (`M.cy` — верх экрана в координатах карты). На карте улица открывается по отпусканию пальца без сдвига, сдвиг больше 8 px — прокрутка. Новые улицы: `NODES` + `DISTRICTS` в `js/map.js`.
- Неподвижная часть улицы (трава, рамка, плитки) рисуется один раз в отдельный холст (`drawStatic` в `js/board.js`). Всё, что меняется в игре, рисовать в `drawLevel`, а не там.
- Сложность улицы меряет `tools/rate.js` (`node tools/rate.js` — таблица, `find` — подбор зёрен под оценку). План на 100 улиц — `docs/plan-100.md`: одна глава за заход, сначала этап 0.
- Надписи — только через `t('ключ')` из `js/i18n.js`, сразу на русском и английском (`?lang=en` для проверки). Тесты идут с `?lang=ru`.
- Улицы идут главами по 10 (`CHAPTER`). Глава открывается при 18 звёздах в предыдущей (`GATE`). Карта главы строится сама по образцу второй части: `THEMES` и `place()` в `js/map.js`.
- `rusty:N` у улицы — N ржавых труб со счётчиком поворотов (`left` у клетки, `isStuck` в `core.js`). У ржавых улиц должно быть одно решение.
- `turn:'leaf'` у улицы — крутятся и вводы домов, фонарей, теплиц (`canTurn` в `core.js`); `slack` — запас ходов.
- Готовые улицы менять нельзя: `tests/generator.test.js` сверяет их отпечаток. После новой главы — увеличить `DONE` и обновить отпечаток.
- Звук — `js/sound.js` (Web Audio, без файлов). На iPhone звук разрешается только в `touchend`/`click` и молчит при выключенном переключателе звонка — это обходит `unlock()`, не убирать. В цикле `loop(t)` параметр `t` — время, а не перевод: надписи там брать через отдельную функцию.
- Коммиты на русском.
- `hidden:0.3` у улицы — доля труб под люками (`hidden` у клетки). Люк открывает `openHatches` в `core.js`, когда вода, ток или газ дошли до соседней клетки. Люки рисуются в `drawLevel` (не в `drawStatic`).
- План по улицам — `docs/plan-100.md` (сделано 50 из 100: этап 0, главы 3–5; дальше глава 6 «трубы на одном вентиле»). Отдельно: SDK площадки и реклама, раскладка для ПК 16:9, шрифты внутри архива (сейчас Google Fonts), задача дня, витрина.
