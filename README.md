# Родниково

Головоломка для Яндекс Игр: поворачивай трубы и провода, чтобы провести воду, свет и газ по улицам посёлка. 20 улиц. Каждая пройденная улица оживает на карте.

**Играть:** https://gerzlo.github.io/rodnikovo/

## Как устроено

Обычная веб-страница без сборки: HTML, CSS и JS-модули.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка экрана |
| `css/style.css` | оформление кнопок и окон |
| `js/core.js` | логика без браузера: генератор улиц и проверка соединений |
| `js/levels.js` | список улиц: размер (на телефоне до 6×8), сети, зерно, новые элементы |
| `js/art.js` | рисунки: дома, фонари, теплицы, башня, подстанция, газгольдер, природа; реестр объектов |
| `js/board.js` | поле улицы: плитки, водопровод, провода, газовые трубы |
| `js/map.js` | карта посёлка: прокрутка пальцем и колесом мыши, кварталы, табличка «Скоро» в конце дороги |
| `js/fx.js` | частицы: брызги, искры, облачка газа, звёздочки |
| `js/platform.js` | сохранения и реклама (на шаге 2 — Яндекс SDK) |
| `js/state.js` | общее состояние игры |
| `js/main.js` | экраны, кнопки, касания, главный цикл |

## Правила

- **Объекты в клетках стоят по центру.** У каждого объекта в `OBJECTS` (`js/art.js`) записаны габариты, и `drawInCell` ставит середину габаритов в центр клетки. Новую постройку добавляй туда же с габаритами.
- **Сети:** вода (башня → дома, голубой), электричество (подстанция → фонари, жёлтый), газ (газгольдер → теплицы, оранжевый). Клетка источника окрашена в цвет сети. Будущая сеть: отопление — красный.
- **Карта длинная:** внизу улицы 1–10, выше 11–20. Новые улицы — точка в `NODES` и квартал в `DISTRICTS` (`js/map.js`), дорогу продлевать к табличке «Скоро».
- **Метки** (капля, молния, пламя, замок) — всегда в правом верхнем углу клетки.
- **На телефоне — только вертикально.** Если повернуть телефон боком, игра закрывается заставкой «Поверни телефон». Компьютер и планшет она не затрагивает.

## Сложность и план

- `node tools/rate.js` — оценка сложности каждой улицы: сколько волн рассуждений нужно и сколько труб остаётся неясными.
- `docs/plan-100.md` — план на 100 улиц: главы, новые правила, таблица улиц с целями по сложности.

## Проверка

- `npm test` — тест генератора (все улицы и 600 случайных настроек) и автотест в браузере: проходит все улицы касаниями, проверяет проигрыш, подсказку, перезагрузку, разные экраны и скорость.
- GitHub запускает тесты при каждом изменении в `main` и публикует игру, только если они прошли. Скриншоты теста: вкладка **Actions** → последний запуск → **Artifacts**.
- Известные проблемы помечены в тесте как «ИЗВ.» и не мешают публикации.
- Локально: `npm run serve` → http://localhost:8080
